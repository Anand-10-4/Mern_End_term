# AmberRoast OS - Frontend Application

The modern, responsive web interface for AmberRoast OS, built with React, Vite, and TailwindCSS. Designed with an artisan craft aesthetic utilizing the specified warm amber palette:
- Soft Cream Gold: `#F9E6A8`
- Vibrant Honey Amber: `#F2A900`
- Roasted Warm Amber: `#CC6F00`
- Deep Espresso: `#4D2A00`

---

## ☕ Key UI Capabilities

1. **Executive Lab Dashboard**: Live telemetry KPIs, roast shrinkage metrics, and real-time operational audit log feed.
2. **Allocation Marketplace**: Faceted filters by origin country, processing method, and minimum SCA score with dynamic search.
3. **Interactive SCA Cupping Lab**: Standardized 10-attribute scoring bench with dynamic SVG radar wheel, defect deduction calculation, and instant grade classification.
4. **Lot Detail & Terroir Profile**: Chemistry breakdowns (moisture %, density, MASL elevation), roast profiles, and cupping history.
5. **Wholesale Escrow Ledger**: Milestone progression tracker (`escrow_held` -> `roasting_scheduled` -> `cupping_verified` -> `dispatched` -> `delivered` -> `escrow_released`).
6. **Digital Certificate of Authenticity**: Printable tamper-proof quality certificates with cryptographic verification seal.
7. **1-Click Evaluator Persona Switcher**: Instant switching between Roaster, Buyer, Q-Grader, and Admin roles.

---

## 🛠 Local Setup

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```
The application will be live at `http://localhost:5173`.
