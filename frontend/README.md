# GoldenCrust Bakery - Frontend Application

The user-friendly, responsive web interface for GoldenCrust Artisan Bakery & Custom Cake Studio, built with React, Vite, and TailwindCSS.

Designed with an inviting, artisan craft aesthetic utilizing the specified warm amber and golden honey palette:
- Soft Cream Butter: `#F9E6A8`
- Vibrant Honey Amber: `#F2A900`
- Baked Warm Caramel: `#CC6F00`
- Dark Chocolate Espresso: `#4D2A00`

---

## 🥐 Key UI Workflows

1. **Daily Fresh Bakes Menu**: Real-time batch inventory, stock counters, category filters (Breads, Croissants, Tarts, Savory), and dietary tags.
2. **Interactive Custom Cake Studio**: Dynamic tier selection, sponge flavors, hand-whipped frostings, custom piped message preview, and real-time pricing calculation.
3. **Cart & Instant Checkout**: Support for promotional coupons (`GOLDEN10`), loyalty point redemptions ($1 off per 10 points), and pickup/delivery options.
4. **Live Kitchen Tracker**: 5-stage order preparation pipeline (`Order Placed` -> `In Deck Oven` -> `Glazing & Decor` -> `Ready on Shelf` -> `Completed`).
5. **Bakery Operations Telemetry**: Revenue metrics, daily sell-through rate, kitchen queue load, and activity feed.
6. **1-Click Evaluation Persona Switcher**: Instant switching between Customer, Chef Baker, and Store Manager roles.

## 🛠 Local Setup

```bash
# Install dependencies
npm install

# Start Vite dev server (Port 5173)
npm run dev

# Build production bundle
npm run build
```
